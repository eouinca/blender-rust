# Как получить APK

В этой папке находится исходный Android/Rust-проект и GitHub Actions workflow для автоматической сборки APK под Android ARM64.

**Важно:** готового APK в этом архиве пока нет. В среде, где был подготовлен архив, отсутствуют Android SDK/NDK и Gradle, поэтому я не стал подкладывать фиктивный APK.

## Сборка через GitHub
1. Создай репозиторий на GitHub и загрузи туда всё содержимое этого архива.
2. Открой вкладку **Actions**.
3. Выбери **Build Android APK** и нажми **Run workflow** (или дождись сборки после push в main/master).
4. После успешной сборки открой запуск workflow и скачай artifact **blender-rust-apk**. Внутри будет `app-release.apk`.
5. Перенеси APK на Android и установи. Если Android спросит, разреши установку из этого источника.

Сборка рассчитана на ARM64 Android (`arm64-v8a`). Это стартовое приложение для проверки связи Android ↔ Rust, не полноценный Blender и пока не содержит 3D viewport.
